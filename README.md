# Society . E X E

Society . E X E is a public-facing site about defensive cybersecurity and
security education. Its content focuses on authorized assessment, secure
design, security awareness, and incident readiness.

## Run locally

1. Install Node.js 20.9 or later.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Open [http://localhost:3000](http://localhost:3000).

## Available scripts

- `npm run dev` starts the local development server.
- `npm run lint` checks the project with ESLint.
- `npm run build` creates the static production export in `out/`, ready to
  deploy to a static hosting provider.

## Responsible use

All security work must be authorized and limited to a clearly agreed scope.
This project focuses on education and protective practices.
